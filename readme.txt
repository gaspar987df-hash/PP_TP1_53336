Programacion Orientada a Objetos en Java
Este proyecto modela un sistema para la administracion de eventos universitarios
Permite crear eventos y asignarles una sala
Cada evento tiene actividades que pueden ser charlas o talleres
Los estudiantes se pueden inscribir en estas actividades

El modelo aplica conceptos como herencia polimorfismo composicion y agregacion
Se utiliza Java y se implementa una jerarquia de clases para calcular los costos de los eventos y administrar las inscripciones

El proyecto incluye la documentacion de las relaciones en memoria
